# Windows Reinstallation and PC Factory Restore Guide

## Prerequisites
- Windows installation media (USB drive 8GB+)
- Internet connection for downloading Windows and drivers
- External drive for backing up data
- Your Windows product key (if applicable)

## 1. Back Up Important Data
Before proceeding, back up ALL important data:
- Documents, photos, videos, music
- Browser bookmarks and saved passwords
- Email configurations
- Game saves
- Software license keys
- Important settings and configurations

## 2. Create Windows Installation Media
1. On a working computer, go to: https://www.microsoft.com/software-download/windows10
2. Download the Media Creation Tool
3. Run the tool and select "Create installation media for another PC"
4. Choose your language, edition, and architecture
5. Select "USB flash drive" as your media
6. Follow the prompts to create the installation media

## 3. Reinstall Windows on F Drive
1. Connect your USB installation media to the PC
2. Restart your computer and boot from the USB drive:
   - Press the boot menu key during startup (often F12, F2, ESC, or DEL)
   - Select the USB drive from the boot menu
3. When Windows Setup launches, select your language and click "Next"
4. Click "Install Now"
5. Enter your product key or click "I don't have a product key" to activate later
6. Accept the license terms
7. Select "Custom: Install Windows only (advanced)"
8. You'll see all available drives:
   - Look for your F: drive in the list (verify by size)
   - Select it and click "Format" to prepare it
   - After formatting, select it and click "Next"
9. Windows will now install on your F: drive
10. Follow the setup process to configure your Windows installation

## 4. Factory Reset Your PC (Primary Drive)
After installing Windows on F drive, you can factory reset your primary drive:

### Method 1: Using Windows Reset Feature
1. Boot into your new Windows installation on F: drive
2. Go to Settings > Update & Security > Recovery
3. Under "Reset this PC", click "Get started"
4. Choose "Remove everything"
5. Select "Only the drive where Windows is installed" (this will be your primary drive)
6. Choose between "Just remove my files" (faster) or "Fully clean the drive" (more secure)
7. Click "Reset" and wait for the process to complete

### Method 2: Using Manufacturer Recovery Partition
Many PCs have a recovery partition with factory image:
1. Restart your computer
2. Press the recovery key during startup (varies by manufacturer):
   - HP: F11
   - Dell: F8
   - Lenovo: F11 or Novo button
   - ASUS: F9
3. Select factory reset or recovery option
4. Follow the prompts to restore your PC to factory settings

## 5. After Reinstallation
1. Install all Windows updates
2. Install drivers for your hardware (download from manufacturer websites)
3. Install your antivirus software
4. Restore your backed up data
5. Reinstall necessary applications

## Important Notes
- Factory reset will erase ALL data on the selected drive
- Make sure your backup is complete before proceeding
- Have your network drivers ready for reinstallation (download on another device if needed)
- The process may take several hours to complete
- If you have a laptop, keep it plugged in during the entire process
