Sound Files for Block Breaker

Place the following sound files in this directory:

1. menuhover.wav - This will play when the mouse hovers over a button
   - Should be short (0.1-0.2 seconds)
   - Subtle, non-intrusive sound
   - Recommended: soft clicks, whooshes, or subtle UI sounds

2. click.mp3 - This will play when a button is clicked
   - Short, satisfying click sound
   - Should provide good feedback for user actions
   - Recommended: mechanical click, tap, or UI selection sound

3. menu_music.ogg - Background music for the main menu
   - OGG format is recommended for better compression
   - Should loop well
   - Recommended: ambient, non-distracting music that fits the game's theme

Additional sounds you might want to add later:
- piece_rotate.wav - When rotating game pieces
- piece_drop.wav - When pieces land
- piece_move.wav - When moving pieces horizontally
- cluster_form.wav - When a cluster is formed
- level_complete.wav - For level completion
